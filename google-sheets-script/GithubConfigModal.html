Configuración de sincronización automática con GitHub

Permite que las modificaciones realizadas en Google Sheets se publiquen automáticamente en el repositorio sin intervención manual del programador.

  1. Genera un Personal Access Token (PAT) en GitHub: Settings > Developer settings > Personal access tokens.
  2. Selecciona permisos de escritura en el repositorio (permiso repo o Contents: Read and write).
  3. Pega el token abajo y verifica la conexión.
Usuario u organización de GitHub.
Nombre del repositorio web.
Rama donde se despliega GitHub Pages (habitualmente 'main').
El token se almacena de forma segura en las propiedades privadas del script. Dejar en blanco para mantener el token actual.
